# Privacy Policy: Running Coach

Running Coach is a personal, self-hosted tool. It is used only by its owner, to analyze their own
Strava and WHOOP data.

- **What it accesses:** read-only access to the owner's Strava activities and WHOOP recovery, sleep,
  cycle, workout, profile and body-measurement data, through the official APIs and OAuth.
- **Where data is stored:** only on the owner's own computer (`~/.running-coach/`). Nothing is sent to
  any server run by this project.
- **Sharing:** data is shared only with the AI assistant (Claude) that the owner chooses to connect,
  and only when the owner asks it a question. It is never sold or shared with third parties.
- **Writing:** the app never creates, edits or deletes anything in Strava or WHOOP.
- **Deletion:** the owner can revoke access at any time in Strava/WHOOP settings and delete
  `~/.running-coach/` to remove all stored tokens and cached data.

Contact: the repository owner, via GitHub (https://github.com/whosjoey).
